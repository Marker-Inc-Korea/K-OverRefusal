# merged_v2 벤치마크 — 재구축 harmful set에서 한국어 LLM 과잉거부·안전성 평가 (K-SafeGuard judge)

작성 2026-07-07 · **갱신 2026-08-24 (비교 모델 최신화: 최신 국내 LLM 확장 + EXAONE-4.5 재실행)** · 데이터 `dataset/final/merged_dataset_v2.jsonl` (485개) · 판정 모델 **K-SafeGuard** (`kanana-modguard-fr-kidiom-2ep-merged`, 로컬 vLLM)

## 1. 목적

harmful 대조군을 재구축한 [merged_v2](../harmful_rebuild/리포트.md)에서 모델의 **과잉 안전 거부(over-refusal)** 와
**유해 요청 거부(safety)** 를 함께 측정한다. 판정은 자체 한국어 모더레이터 **K-SafeGuard**로 수행(외부 API 미사용).
2026-08 갱신에서는 "비교 모델이 오래되고 작다"는 피드백을 반영해 **최신 국내 개발 LLM**(Naver·LG·SKT·Trillion 등)으로
라인업을 확장하고, 하이브리드 사고(thinking) 모델의 판정 오염 문제를 교정했다.

## 4. 방법

- **추론**: `prompt_ko` 입력, 온도 0.0, max_new_tokens 2048, `--skip_mm_profiling`, 모델별 `max_model_len` 자동 클램프.
  신규 모델은 vLLM 0.25.1 환경(`vllm_env`; 신형 아키텍처 지원), **판정은 종전과 동일한 vLLM 0.22.1 환경 + K-SafeGuard**로
  수행해 기존 수치와의 비교 가능성을 유지.
- **하이브리드 사고 모델 처리(신규)**: Qwen3/EXAONE-4.x/HCX-Think류 템플릿에 `enable_thinking=False`(HCX는 `thinking`)를
  전달해 **non-thinking 모드로 통일**하고, 출력에 남는 `<think>…</think>` 블록은 특수토큰 보존 디코딩 후 분리해
  `response`(최종 답변)와 `reasoning` 열로 나눈다(`finish_reason` 열로 절단 추적). 판정은 최종 답변만 대상.
- **HF 러너(커스텀 아키텍처)**: vLLM이 모르는 원격 코드 모델(VAETKI)은 `eval/run_inference_hf.py`(transformers `generate`, 좌측 패딩 배치 16, greedy)로
  같은 스키마의 출력을 만든다. VAETKI 템플릿은 사고(`<think>`)를 항상 켜고 끄는 스위치가 없어 **사고 모드 그대로** 생성(max_new_tokens 4096)한 뒤
  사고 블록을 분리하고 최종 답변만 판정 — 따라서 VAETKI 행은 다른 모델(non-thinking)과 추론 모드가 다르다는 점을 감안해 읽어야 한다.
- **평가**: K-SafeGuard가 WildGuard 포맷으로 refusal/compliance 2분류. 그룹은 `k_idioms` 쌍과 `xstest`(일반 benign + `harm_*`).
- 지표: safe_compliance(무해 정상응답률↑), safe_overrefusal(↓), unsafe_refusal(유해 거부율↑), behavior_acc, refusal_f1.

### 4.1 EXAONE-4.5-33B 재실행 (판정 오염 교정)

EXAONE-4.5-33B는 템플릿 기본값이 **thinking ON**이라 기존(7월) 실행에서는 사고 텍스트가 특수토큰 제거와 함께 답변에
그대로 붙은 채 판정되었다(응답 평균 5,966자, 영어 사고 서두 "Okay, the user is asking…" 포함). non-thinking으로 재실행한
결과 **safe_compliance 0.492→0.665, behavior_acc 0.722→0.765**로 크게 달라졌다(기존 산출물은
`outputs/remote_models/EXAONE-4.5-33B/merged_v2_legacy_thinking/` 보관). 사고 텍스트 혼입은 응답 자체와 judge 판정을
모두 왜곡하므로, 하이브리드 사고 모델 평가에서 반드시 통제해야 할 요인이다.

## 6. 해석

- **EXAONE-4.5-33B(non-thinking)가 균형 지표 종합 1위**(behavior_acc 0.765·f1 0.813). 재실행 전 수치는 사고 텍스트
  혼입 아티팩트였다(§4.1).
- **스케일업은 과잉거부보다 안전성을 개선**: A.X-4.0 72B는 7B Light와 무해 정상응답률이 동일(0.627)하지만
  유해 거부율 0.730→0.823, behavior_acc 0.691→0.749로 상승 — 같은 계열에서 크기 증가가 주로 유해 판별력을 키움(종합 2위).
- **최신 모델이라고 과잉거부가 나아지지 않는다**: 2025-12 공개된 HyperCLOVAX-SEED-Think-32B는 non-thinking 모드에서
  무해 요청의 87%를 거부(safe_compliance 0.130) — 전 모델 중 최악. privacy 0.04·euphemism 0.05·legality_framing 0.07 등
  전 카테고리에서 도덕적 훈계형 거부가 지배적이며, 유해 거부율(0.957)은 최고여서 **안전 쏠림(over-alignment)의 극단 사례**.
- **과잉거부–안전성 트레이드오프는 여전히 뚜렷**: EEVE(0.85/0.32)의 과소거부 ↔ HCX-Think-32B(0.13/0.96)의 과잉거부가
  양극단을 이루고, 그 사이에서 EXAONE-4.5가 가장 좋은 균형.
- **k_idioms는 여전히 난제**: 신규 모델도 k_idioms 정상응답이 일반 benign보다 낮거나(HCX-Think 0.26)
  비슷한 수준(EXAONE-4.5 0.76)에 그침.

사고 과정에서 위험 해석을 증폭한다. 과잉거부 평가에서 추론 모드를 명시·통제해야 하는 또 하나의 근거.
